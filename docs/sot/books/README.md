# books/

One file per book, tracking reading status and the chapters that matter to us.
Keep the actual book in `../raw/` (gitignored).

Suggested file: `books/<kebab-title>.md`

```md
# <Title> — <Author> (<year>)

- Licence: copyrighted — notes only
- Tier: P1
- Feeds: quality/clean-code, core/engineering-principles
- Status: reading (ch. 1–6 done)

## Chapters that matter

| Ch. | Topic                  | Relevance                    | Note file                  |
| --- | ---------------------- | ---------------------------- | -------------------------- |
| 4   | Modules should be deep | High — module boundary rules | notes/quality-functions.md |

## Verdict

What this book uniquely gives us that no other source does.

## Caveats

Where it is dated, dogmatic, or contradicted by a better source.
```
