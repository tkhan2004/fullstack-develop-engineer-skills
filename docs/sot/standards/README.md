# standards/

RFCs, specifications and conventions. Most are freely redistributable, but **still do not
paste full texts** — link, cite, and store only the clauses we actually use.

Starter set:

| File                          | Source                  | Use                                      |
| ----------------------------- | ----------------------- | ---------------------------------------- |
| `rfc-2119-keywords.md`        | RFC 2119 / 8174         | MUST/SHOULD/MAY in all specs and skills  |
| `rfc-9457-problem-details.md` | RFC 9457                | HTTP error response shape                |
| `rfc-9110-http-semantics.md`  | RFC 9110                | Status codes, methods, caching semantics |
| `semver.md`                   | semver.org              | Skill/manifest/package versioning        |
| `conventional-commits.md`     | conventionalcommits.org | Commit convention                        |
| `twelve-factor.md`            | 12factor.net            | Configuration and environment rules      |
| `keep-a-changelog.md`         | keepachangelog.com      | CHANGELOG format                         |

Each file records: what the standard requires, which of our rules depend on it, and any
deviation we deliberately make (with the reason).
