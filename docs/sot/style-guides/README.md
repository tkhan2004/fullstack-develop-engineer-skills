# style-guides/

Published style guides, recorded as **decisions with rationale**, not as copied rules.

| File                      | Source                        | Licence | Use                                                        |
| ------------------------- | ----------------------------- | ------- | ---------------------------------------------------------- |
| `google-typescript.md`    | Google TypeScript Style Guide | CC BY   | Naming, imports, type usage                                |
| `google-eng-practices.md` | Google Engineering Practices  | CC BY   | Code review standard                                       |
| `airbnb-javascript.md`    | Airbnb JS Style Guide         | MIT     | Historical reference; much is now ESLint/Prettier defaults |
| `react-conventions.md`    | react.dev + community         | —       | Component and hook conventions                             |

For each adopted rule, record: the rule, the rationale, and whether we adopt, adapt or reject
it. A style guide we merely cite without a position is not useful here.
