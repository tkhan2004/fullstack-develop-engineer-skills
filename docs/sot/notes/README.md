# Notes

Distilled, citable notes written in **our own words**. These are committed; the sources they
come from are not.

Naming: `<domain>-<topic>.md` — `quality-naming.md`, `architecture-dependency-rule.md`,
`security-authorization.md`, `testing-levels.md`, `database-indexing.md`.

Start from [`_TEMPLATE.md`](_TEMPLATE.md).

A note is finished when:

- its **Extracted rules** table has at least three `actionable` rows;
- disagreements between sources are recorded with our position and reasoning;
- the skill it feeds references it via `skill.yaml` `sources[]`.

Special file: `skill-evaluations.md` — before/after records from the
[behaviour test](../../04-checklists/skill-authoring-checklist.md#8-behaviour-test-do-not-skip).
